# Municipal Complaint Management System

A web-based Municipal Complaint Management System that allows
users to register complaints and helps municipal administrators
manage, track and update complaint status.

## Technology Stack

### Frontend

* React
* Vite

### Backend

* Spring Boot
* Java 17
* RESTful API

### Database

* MySQL

### ORM

* Spring Data JPA
* Hibernate

### Security

* Spring Security
* JWT

### API Testing

* Postman

### Build Tool

* Gradle - Groovy

### Version Control

* Git
* GitHub
